# S4 外网发行与真实端到端验收

状态：pending。任务类型：HITL。

需求：[PRD](../../../docs/prd/universal-onboarding.md)；技术方案：[开发设计](../../../docs/design/universal-onboarding.md)；交接：[进度](../../../docs/handoff/universal-onboarding/progress.md)。

## 目标与依赖

依赖 S3。将此前模拟验证提升为外网真实发行包、真实宿主和测试后端的完整验收。

## 执行前提

- 由用户/环境负责人提供外网测试后端、相应后端源码或可核对的实际契约。
- 明确 npm scope/测试制品源、发布权限、测试账户和允许上传的虚构会话。
- 明确需要的发布操作授权。方案确认不等于可任意使用第三方服务或发布到未指定组织。
- 前提未到位时记录具体缺口，不将本地模拟或此前内网授权视为外网验收完成。

## 范围与模块线索

发行清单、CI、目标平台构建、实际 npm 包或指定测试制品源，以及真实 UI/网络验收报告。

## 验收标准

- [ ] 冻结源码/发行包/核心/宿主版本与摘要，记录可复现安装入口。
- [ ] 干净用户环境从指定测试源安装，首次接入不需要 setup/PATH/手填 URL。
- [ ] 真实网页设备授权完成，登录后授权上下文没有丢失。
- [ ] 一条虚构会话及适用子会话完整同步，具备脱敏、恢复和最终同步证据。
- [ ] 暂停、取消、后端不可达、失效授权、升级与回退均有实际验收结果。
- [ ] Windows 的宿主、插件、核心及其后台子进程没有非预期可见终端。
- [ ] 测试报告明确通过、失败、未验证项目，不记录密钥和真实会话内容。

本任务不部署内网、不自动上传真实工作会话、不隐式发布正式生产版本。
