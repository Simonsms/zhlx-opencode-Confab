# S1 首次接入与授权闭环

状态：pending。任务类型：AFK。

需求：[PRD](../../../docs/prd/universal-onboarding.md)；技术方案：[开发设计](../../../docs/design/universal-onboarding.md)；交接：[进度](../../../docs/handoff/universal-onboarding/progress.md)。

## 目标与依赖

依赖 S0 的版本和宿主行为验证。实现完整但最小的首次接入路径，不要求用户运行 setup、填写 URL、安装 Go 或配置 PATH。

## 范围与模块线索

- 插件发行包携带目标平台核心、环境预设及摘要清单，程序准备过程使用不可变版本目录和并发保护。
- 新增 `cmd/integration*.go` 和 `pkg/onboarding/`，从 `cmd/login.go` 提取业务逻辑供 CLI 与机器入口共用。
- `pkg/confabpath/` 与 `pkg/config/` 支持完整环境上下文，区分外网和内网的凭据、日志、状态与物化文件。
- 复用现有 provider、daemon、脱敏和增量上传，不重写同步引擎。
- 参数、状态和目录按设计第 5–8 节实现；新增接口尚不存在，须先定义类型与合同测试。

## 验收标准

- [ ] 新用户在隔离的标准宿主中添加插件后，预置后端与核心自动就绪，无 setup/PATH/手填 URL。
- [ ] 首次授权与宿主初始化解耦，不因浏览器授权等待阻塞 OpenCode。
- [ ] 已有同环境凭据校验有效后复用；不复用另一个后端的凭据。
- [ ] Windows 浏览器唤起正常；用户登录后能够继续设备授权，失败时提供清晰链接。
- [ ] API Key 不进入插件返回值、命令行、模型上下文或日志。
- [ ] 首次无授权不启动采集；授权成功后只协调仍活动的会话。
- [ ] 通过共享核心完成一条虚构会话的采集、脱敏和增量上传。
- [ ] 托管核心不自行查询或更新公网 latest。
- [ ] 包损坏、平台/协议不兼容、不可达等失败不拖垮宿主。

## 外部前提与验证

可以先用本地模拟后端实现和验证，结果只能标记为模拟验证。真实后端契约应读取实际 handler；外网测试后端尚未指定，不能把此前内网地址或第三方公共服务代入。

复用 `pkg/opencodetest/`、`pkg/backendtest/` 与 `test/portable/`。新增状态、隔离和协议测试使用 TDD；对最终插件包运行真实宿主测试并记录具体命令。

本任务不修改 OpenCode 源码、不发布公网包、不部署内网，不复制用户真实会话作为测试数据。
